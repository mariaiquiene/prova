# Prova de Lógica em JavaScript

Prova de lógica de programação em JavaScript puro, com 8 questões divididas em três partes:

- **Parte 1 (fáceis):** questões 1 a 5
- **Parte 2 (médias):** questões 6 e 7
- **Parte 3 (desafio):** questão 8

Cada questão tem um arquivo `.js` próprio com o nome da função a ser implementada, uma descrição curta e um bloco de testes no final. O bloco de testes imprime `OK` quando a função passa no teste e `ERRO` quando não passa.

## Como resolver

1. Abra o arquivo da questão no seu editor.
2. Escreva a função no lugar do comentário `// escreva sua solução aqui`.
3. Execute o arquivo no terminal:

   ```bash
   node q1-soma.js
   ```

4. Confira se todas as linhas mostram `OK`.

Não altere o bloco de testes no final de cada arquivo.

## Regras

- Use a função com o nome indicado e retorne o resultado com `return`.
- Não use `prompt` nem leitura de dados.
- Você pode usar métodos prontos de array, como `map`, `filter` e `reduce`.
- Tempo total: 90 minutos.

## Requisitos

- Node.js instalado (versão 18 ou superior recomendada).
